So what are the next steps? Once you're done with the architecture, without losing a heartbeat, you turn around to design the project to build it. You must present to decision makers the system architecture and the project you're going to use to build it. And the project design is going to tell you how long it will take, how much will it cost, and so on.

Project design requires the effort estimation for activities, building dependency trees based on your culture and your sequence diagram. Analyzing the critical paths, assigning the resources, scheduling, calculating the cost, and evaluating the risk. All of that is part of project design, which I'm going to have a separate presentation on.
