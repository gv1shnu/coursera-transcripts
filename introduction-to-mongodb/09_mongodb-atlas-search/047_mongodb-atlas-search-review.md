Wow, Atlas search has a lot of features and we've just scratched the surface. We learned how Relevance-based search is used. How Atlas search works. How to create a search index.

How to use field mappings to make that search index more efficient and relevant. How to create an aggregation stage where the search term will be queried. How to customize the way that the results are being returned using the compound operator and how to organize the search results using facets. That's so much.

It will take some practice to get used to all of these features and the new syntax. The next big step is to take a look at the MongoDB docs and see how to implement search in your language of choice in an application. Your users will love being able to surface the information that they're looking for so easily.
