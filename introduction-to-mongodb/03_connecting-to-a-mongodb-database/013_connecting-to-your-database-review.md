>> Congratulations on completing this unit. Now you've learned different ways to connect to your MongoDB database by using your connection string. You've also learned how to troubleshoot common connection issues. We use the MongoDB connection string to connect to our database from the Mongo shell, compass, or an application.

Remember that your connection string can be easily accessed from your Atlas project dashboard, just click the connect button on your desired cluster. This will open a separate window with several options to connect using your connection string. First, we used our connection string to connect to our database through the Mongo shell. Once connected, we explored how to use the Node.js REPL environment by creating functions, variables and loops.

Next, we installed MongoDB Compass and used it along with our connection string to connect to our database. Compass is a graphical user interface for our databases, with Compass, we can read, write, update and delete our data without having to write any code. We also discussed how to connect an application to MongoDB using our connection stream. Remember, MongoDB offers driver support for common languages such as JavaScript, C#, Python, and Java.

Finally, we learned how to troubleshoot common connection issues related to network access and user authentication. While we didn't cover every type of error, this overview should provide a solid foundation so that you can troubleshoot some of the most common connection issues. Now that you can connect to MongoDB by using a connection string, try implementing CRUD methods from the command line or an application using the language driver of your choice. To do this, check out our units on CRUD or review MongoDB's documentation.

Congratulations on completing this unit on connecting to MongoDB, until next time, keep coding.
