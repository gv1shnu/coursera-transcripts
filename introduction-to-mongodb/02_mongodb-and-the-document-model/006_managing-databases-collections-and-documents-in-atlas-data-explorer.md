Welcome back team, in this video, we'll learn to manage data in MongoDB using the Atlas Data Explorer. Data Explorer is Atlas's built-in tool to visually interact with and manage data from within the Atlas UI. While developers often interact with MongoDB instances using the command line, many also use the Data Explorer to view and manage their data in both development and production databases. To get started with this tool, we'll use the Data Explorer to create and view databases, collections, and documents in an Atlas database deployment.

Let's get started by viewing the databases in our Atlas cluster. So, let's go ahead and get started with working with databases in our Atlas cluster. If you don't see the screen that I have on the screen right now, you can go ahead and click on the Databases link on the left hand menu. This will bring you to the Database Deployments page in which you can go ahead and click the Browse Collections button on your particular database in order to access the Data Viewer.

This Data Explorer has lots of different menus to allow you to see all of the different collections and databases available on your deployment. As you can see on the left hand side, we can take a look at the databases here in the Sample Training and Sample Inflicts, and all the different databases we have here. And under each one of those databases, their corresponding collections. Let's go ahead and take a look at one of these collections.

By clicking on the collection, the view changes so that I can see the individual documents that exist within that collection. This view also allows me to see the total storage size of the collection and the total number of documents. So far, we've viewed our data in Atlas, but we can also create databases, collections, and documents. Say we're going to create a database to store data related to a new blog we're creating.

So, again, our goal here is to create a new database for this brand new blog that we're creating. To do that, we'll click on the Create Database on the left hand menu. Clicking this will bring up a new modal box in which we can enter a new database as well as the first collection under that new database. I'll go ahead and call the database blog, and under this blog, we'll create a new collection for our posts.

You can see that there's additional preferences which we won't be using here, but feel free to go through our documentation to learn more about those. Clicking on the Create button will create this new database within the Database Deployment, which we can click on blog and then click on post in order to see the collection. What if we have an existing database though that we want to add an additional collection too? To do so, you can click on Blog, click on Create Collection on the right hand side, and another dialog box will open which will allow us to create an additional collection.

Let's say for this one, we want to create a collection for our comments. And again, I'll click on the Create button. You can now see that under the blog database, I have both the Posts and the Comments Collections available to use. Now, let's say I want to create my first document within my blog.

This new document is probably going to go under Posts, so let's go ahead and go into that collection and create our new document. First, I'll click on the Posts Collection, and on the right hand side, you'll see that we have the ability to insert a new document. Let's go ahead and click on that. In the modal box that opens you'll see that you have the ability to edit a Json like document which can be inserted into the collection.

I'm going to go ahead and add two new fields for my name and age to this document. First, we'll use the name, which will be a string field. Then I'll add an additional field of an integer for my age. Once this is done, I'll go ahead and click on the Insert button to insert this document into my Posts Collection.

And we can now see in the Data Explorer that the new document has been created in that Post Collection. Great job, we've covered many of the basic actions that you can take to manage your data using the Atlas Data Explorer. We learn to view and create databases, collections, and documents. There's lots more you can do with the Data Explorer, such as editing and deleting your data, as well as writing and testing queries.

With this foundation, you're ready to use the Data Explorer to manage your Atlas data and to leverage its functionality in your projects.
