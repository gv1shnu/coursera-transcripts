>> Congratulations on completing this unit. You now know how to use Aggregation in MongoDB. Aggregation is a way to filter, sort, group reshape, and analyze data without changing any data in your collection. You can use Aggregation to answer questions and gain insights from the data in your collections.

We covered a lot in this unit, starting with how to create an Aggregation Pipeline and the components of a stage. We also cover different stages, including match, group, sort, limit, project, set, count, and out. We created Aggregation Pipelines while keeping in mind that the order of stages specifies the order of operations that the data will go through. You might already have a lot of ideas about how you can use an Aggregation Pipeline to quickly and easily find answer hidden in your data set.

Give it a try if you get stuck. MongoDB offers extensive documentation for all these Aggregation stages and others.
