>> Hello. In this video, you will learn how to use out to create a new collection from the output of an Aggregation pipeline. Out is one of my favorite stages because it's so easy to use. The Out Aggregation operator writes documents that are returned by an Aggregation pipeline into a new collection.

So out must be the last stage in the pipeline. You should be aware that out creates a new collection if it does not already exist. But if the collection exists, out replaces the existing collection with new data. So be mindful of what you name this new collection.

Unless you want an existing collection to be overwritten, the out stage receives the database in the DB field and the collection name in the Call field. If the database or the collection that you specified doesn't exist, it's created. Another way to use the outstage is to provide only the collection name. In this case, the outstage uses the same database used in the Aggregation.

As you know, the aggregate command can use different Aggregation stages such as match to filter documents, and Group to combine them. Out can then be used to output the results generated by the pipeline. Here's an example. We'll use the Zips collection in the training database for our Aggregation operation.

We have two stages grouping the data by state and summing the total population in all the Zip codes using Group. Then we use match to keep only the states where the total population is less than 1 million. After executing this command, we get eight documents from the pipeline. These are the states with the populations of less than 1 million people.

Now, let's add a third stage in this pipeline by using out. We add out as the last stage in the pipeline to store the output in a collection called Small underscore States in the same database. When we execute this command, we don't get an output in the command line. The results of the Aggregation pipeline are written to a new collection.

We can confirm this by viewing our collections. We see that there's a new small underscore states collection in this database. If we retrieve the data from this collection by using the Find command, we'll see that the new collection contains exactly eight documents that were the result of the Aggregation pipeline. Perfect.

In this lesson, you learned how to store the Aggregation pipeline output into a collection by using the out stage. For next steps, you may want to review other Aggregation stages. To do this, check out the documentation for Aggregation pipeline stages on the MongoDB website.
