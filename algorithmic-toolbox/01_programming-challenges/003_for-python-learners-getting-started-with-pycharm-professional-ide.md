Hi there. If you're learning Python, we recommend completing the programming assignments in PyCharm. Working in a professional IDE will help you practice real development workflows, including writing, running, testing, and debugging your code. In this video, you'll learn how to install PyCharm, open learning projects, navigate the IDE, and work with programming tasks.

Once your environment is set up, you'll be able to complete the Python versions of the assignments directly in PyCharm throughout this course. Let's get everything ready and start coding. First, enter your name and launch the app. And one important thing, remember to accept the code of honor for every task.

Without it, your progress might not sync. Next, click Download to get the JetBrains Toolbox. JetBrains Toolbox is like a central hub for all JetBrains tools. It helps you easily install and manage IDEs, like PyCharm.

Once the toolbox is ready, click Start Coding. This will start downloading PyCharm. PyCharm is a professional Python development environment that lets you run your course projects efficiently. Now, click Start Coding one more time.

Your course will open right inside PyCharm. You are now ready to solve programming assignments in PyCharm. The Course View panel lists all course modules and tasks. Double-click any task to open it.

You can hide or show Course View by clicking this button or pressing Command plus 1 to give you more space to focus. The editor is your coding playground. Here, you'll write your Python programs and experiment freely. When you need to run code, simply press Control plus R, or select Run from the menu.

To maximize space, use Shift plus Command plus F12 to hide or show all panels instantly. The Task Description panel gives clear instructions for each task, whether it's theory, quizzes, or coding assignments. You can check solutions, move between tasks, and even peek at answers if you get stuck. We recommend keeping this panel open or move it to another monitor for convenience.

For each Python practice activity in this course, open the corresponding task in the IDE, write your solution, and use the check button to verify that your code works correctly. Once the task passes all checks, return to the previous Coursera programming assignment and submit your solution under the My Submission tab to receive your grade. You can follow the same workflow for all Python assignments in this course.
