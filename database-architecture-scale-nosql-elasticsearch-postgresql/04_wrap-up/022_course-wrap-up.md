So thank you for coming with me on this journey that I call Postgres for Everybody. I hope that you enjoyed the range of topics that we covered. I know for me that I had a lot of fun building the course and the materials. In the beginning, we started with really basic SQL, like perhaps you've seen from me in other classes like Python for Everybody, or Web Applications for Everybody.

But then we added some intermediate SQL techniques, the kind of stuff that I always wanted to teach you, but I never had time. Then we talked a lot about text and JSON and databases. The key thing is that text is a big part of it. Social systems, commenting systems, all that is so important to how we use computers these days.

JSON allows us to do structured and nonstructured data in databases. We've looked at both how relational and NoSQL databases have emerged and evolved over the years. And so I hope that this has given you a really good basis to build on when it comes to your database skills and knowledge, whether you're going to be a data mining expert or a web application developer. I think that you have a good basis for anything that you might want to do going forward in databases.
